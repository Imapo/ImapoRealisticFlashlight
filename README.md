# Miner Helmet Flashlight — мод для tModLoader

Превращает ванильную **Каску шахтёра** (Miner's Helmet) в настоящий
фонарик: пока каска надета, из неё бьёт направленный луч света,
который следует за курсором мыши, реально освещает мир и красиво
рисуется поверх персонажа с сужением у источника и затуханием к краям.

## Как установить / собрать

1. Установите tModLoader (через Steam) и хотя бы раз запустите его,
   чтобы появилась папка модов, обычно:
   `Documents/My Games/Terraria/tModLoader/ModSources`
2. Скопируйте всю папку `MinerHelmetFlashlight` (со всеми `.cs`
   файлами, `build.txt` и `description.txt`) в `ModSources`.
3. Запустите tModLoader → вкладка **Mod Sources** → нажмите
   **Build + Reload** напротив `MinerHelmetFlashlight`.
4. Мод соберётся и появится во вкладке **Mods** — включите его.

## Как это работает

- `MinerHelmetFlashlight.cs` — при загрузке мода процедурно
  генерирует текстуру луча (узкий конус, расширяющийся к концу,
  с плавным затуханием по краям и длине), чтобы не тащить внешний
  файл изображения.
- `FlashlightPlayer.cs` (`ModPlayer`) — каждый кадр проверяет, надета
  ли каска шахтёра (`Player.armor[0].type == ItemID.MiningHelmet` —
  **важно**: `Player.head` для этого не подходит, это отдельный ID
  отрисовки, а не ID предмета), вычисляет направление от головы
  персонажа к курсору и:
  - физически подсвечивает тайлы вдоль луча через `Lighting.AddLight`
    (это настоящий свет, а не просто картинка — освещает пещеры,
    руду и т.д.);
  - хранит текущее направление луча.
- `FlashlightDrawLayer.cs` (`PlayerDrawLayer`) — рисует саму текстуру
  луча поверх персонажа, поворачивая и растягивая её в направлении
  курсора.

## Настройка

- `FlashlightPlayer.BeamLength` — дальность луча в пикселях
  (900 = ~56 тайлов), можно уменьшить/увеличить под баланс.
- В `MinerHelmetFlashlight.GenerateBeamTexture()` можно поменять
  `width`/`height` текстуры, степень сужения (`Math.Pow(t, 0.85)`)
  и яркость затухания (`lengthFade`), чтобы луч был толще/тоньше или
  ярче/тусклее.
- В `FlashlightDrawLayer.Draw()` цвет `beamColor` задаёт оттенок луча
  (сейчас — тёплый белый).

## Возможные доработки

- Добавить лёгкое покачивание луча при ходьбе для реализма.
- Сделать звук щелчка при надевании/снятии каски.
- Добавить альтернативную текстуру-иконку для инвентаря, показывающую,
  что каска теперь "прокачана".
